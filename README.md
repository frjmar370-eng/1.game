# Shotgun 3D — Android

لعبة تصويب 3D موجهة للهواتف بنظام Android.

## التقنية
- Unity 2022.3 LTS
- 3D Mobile
- C#
- Android APK

## النسخة الأولى
- ساحة 3D مولدة برمجيًا.
- لاعب وشوتجن ومؤشر تصويب.
- أهداف 3D متحركة.
- إطلاق، ذخيرة وإعادة تعبئة.
- نقاط وصحة ووقت.
- تحكم لمس مناسب للموبايل.

## البناء
افتح المشروع في Unity 2022.3 LTS أو أحدث متوافق، ثم اختر Android من Build Settings وابنِ APK. Unity يدعم إخراج APK مباشرة لنظام Android.

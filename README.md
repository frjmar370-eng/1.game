# Shotgun 3D

Unity 2022.3.62f2 Android third-person shooter foundation.

## First visible target
- Authored OBJ 3D city mesh, not runtime-generated primitive geometry.
- Authored 3D humanoid player mesh.
- Third-person follow camera.
- Mobile movement/look/fire touch controls.
- In-game HUD with mission, health, ammo and controls.

Open the project in Unity 2022.3.62f2. The editor bootstrap creates `Assets/Scenes/Main.unity` after the model assets finish importing.
